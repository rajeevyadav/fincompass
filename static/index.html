FinCompass

FinCompass is a free research tool, not financial advice and not a recommendation to buy or sell securities. Evidence-score probabilities describe uncertainty in the FinCompass evidence score, not returns. A separate forecast probability is shown only when an empirically trained model passes the configured validation gate, and it applies only to that model's recorded horizon, benchmark, and hurdle. Public data can be incomplete, delayed, biased, or wrong.

Heads up: on free public data a forecast model almost never passes the validation gates — the price signal simply isn't strong enough, and the tool refuses to activate a model that hasn't earned it. Building here is a genuine validation exercise, not a shortcut to a working forecast; expect a "rejected" result. The Evidence score, Screener, Investor Posture and price context all work without any forecast model. Training runs locally and takes several minutes.

Forecast training configuration

Advanced configuration includes horizon, benchmark, hurdle, split fractions, embargo, Bayesian prior strength, ensemble components, calibration, bootstrap depth and validation gates. Edit JSON and validate it here; the validated configuration is applied when you build a forecast model from the Forecast tab.

Adaptive realtime configuration

Provider cadence, staleness, event half-life, Bayesian prior, forgetting/process noise, temporal-breadth gates, calibration limits, drift controls and bounded residual settings are all explicit. Learning-semantic changes create a new adaptive state lineage.
