# FinCompass — hosted demo

Free, transparent stock research: a calibrated probability that a company beats
the S&P 500 over the next year, plus DCF, ratios, options, bonds, portfolio and
risk desks — each in plain language with its assumptions shown.

This Space runs the open-source [FinCompass](https://github.com/rajeevyadav/fincompass)
application. It is an **educational research tool, not financial advice**. The
hosted demo stores no per-user data; for the full experience (including Model
Lab) download the free desktop app from the GitHub releases.
