# FinanceToolkit Adoption Matrix

External reference: <https://github.com/JerBouma/FinanceToolkit> (MIT). This matrix records, per capability area, how FinCompass will (or will not) use it. **No FinanceToolkit code has been copied or vendored yet** — see `THIRD_PARTY_NOTICES.md`. FinCompass's core freeware operation must never require FinanceToolkit or a paid provider.

Decision legend: `ADOPT_CODE` (vendor MIT code, isolated + attributed) · `ADAPT_CONCEPT` (reimplement natively from the public formula) · `USE_AS_REFERENCE` (cross-check only) · `NOT_NEEDED` · `DEFER` (until the retrain/replacement lifecycle is in place) · `BLOCKED_BY_DATA` · `BLOCKED_BY_LICENSE`.

**Implemented so far (native, provider-independent, `ADAPT_CONCEPT`):**
- **performance** (`analytics/performance.py`) — annualized return, volatility, Sharpe, Sortino, max drawdown, Calmar, beta, tracking error, information ratio, downside deviation.
- **risk** (`analytics/risk.py`) — volatility, EWMA volatility, historical/Gaussian VaR, CVaR (expected shortfall), max drawdown + duration. VaR is a confidence-level loss threshold, never "maximum loss".
- Kernel: `analytics/common.py` (transforms + centralized conventions), `analytics/registry.py` (versioned formula registry + universal result contract). Docs: `docs/ANALYTICS_REFERENCE.md` (auto-derived, 16 metrics), `docs/FEATURE_REGISTRY.md`. Verified by hand-calculated tests (`tests/test_analytics.py`) — FinanceToolkit is **not** the oracle.

- **statement normalization** (`analytics/statements.py`) — canonical income/balance/cash-flow schema; provider adapters map raw→canonical (provider vocabulary never reaches a formula); per-value status (reported/mapped/derived/unavailable/not_applicable); missing ≠ zero; derived fields (gross profit, total debt, FCF).
- **ratios** (`analytics/ratios.py`, 25 ratios) — profitability, liquidity, leverage, efficiency, cash-flow, per-share; explicit registered conventions (avg vs ending denominator, EBIT=operating income, EBITDA=EBIT+D&A, total debt=short+long, diluted shares, non-positive/missing denominator → NaN). Verified by hand-calc + pathological tests (`tests/test_statements_ratios.py`).

- **valuation / DCF** (`analytics/valuation.py`) — unlevered (FCFF) enterprise-value DCF built on canonical statements; historical inputs (revenue/EBIT/tax/D&A/CapEx/NWC/net debt/shares, with provenance) kept separate from a distinct assumptions object (growth/margins/WACC/terminal); perpetual-growth and exit-multiple terminal methods; EV→equity→per-share bridge; sensitivity (WACC × terminal growth) and base/upside/downside scenarios. Fails safely on WACC≤0, terminal growth ≥ WACC, invalid shares, currency mismatch, or missing history. Intrinsic value is explicitly not a probability/price target. Verified by hand-calc + boundary tests (`tests/test_valuation.py`).

- **fixed income** (`analytics/fixed_income.py`) — closed-form, user-input-driven bond analytics with no market-data provider: clean price (PV of scheduled cash flows), yield to maturity (bisection on the monotone price-yield function), current yield, Macaulay and modified duration, convexity, and DV01. Conventions registered (coupon-date clean price, `freq` coupons/yr, annual nominal rates compounded `freq`×). Fails safely to NaN on non-positive face/price/frequency, negative maturity, non-finite yield, or an unbracketable target price. A price/yield is an arithmetic identity for the stated terms — not a forecast or guaranteed return. Verified by known-answer tests (par-bond-at-par, zero-coupon duration = maturity, YTM round-trip) + boundaries (`tests/test_fixed_income.py`).

- **options** (`analytics/options.py`) — closed-form Black-Scholes-Merton European call/put pricing with a continuous dividend yield, full Greeks (delta, gamma, vega, theta, rho), and implied volatility recovered by inverting the pricing function. Normal CDF/PDF via `math.erf` (no numpy/scipy dependency). Conventions registered (continuously-compounded rates, annualized vol/time, vega per 1.00 vol, theta per year). Fails safely to NaN on non-positive spot/strike/expiry/vol or a market price outside the bracketable range. An option value/Greek is a model identity for the stated inputs — not a forecast or probability of profit. Verified by tabulated reference values (ATM call ≈ 10.4506), put-call parity, finite-difference Greeks, and IV round-trip (`tests/test_options.py`).

- **portfolio** (`analytics/portfolio.py`) — local-first portfolio aggregation from explicit weights and either a covariance matrix or a historical asset-return matrix: expected return (w·μ), variance/volatility (w′Σw), Euler risk contributions (marginal/component/percent, components summing to portfolio volatility), sample covariance, portfolio return series, and weight normalization. Fails safely to NaN on shape mismatch, non-finite entries, non-square/asymmetric covariance, or zero-sum weights. **Never averages forecast probabilities or model outputs** — it aggregates holdings' risk/return only; nothing promoted to a forecast feature. Verified by hand-calc (uncorrelated two-asset variance, corr-1 volatility, risk contributions summing to vol) + safe-fail (`tests/test_portfolio.py`).

- **factors / econometrics** (`analytics/factors.py`) — ordinary least squares with coefficients, standard errors, t-statistics, R²/adjusted R², and residuals; convenience wrappers for single-factor (CAPM-style) alpha/beta and multi-factor named loadings; rolling market beta. Caller supplies the factor return series (no factor-data license). Fails safely to NaN on insufficient observations, length mismatch, non-finite entries, or a rank-deficient design. **Statistical significance is explicitly not investment significance** — loadings are descriptive in-sample exposures, not forecasts; nothing promoted to a forecast feature. Verified by exact regressions (y=2x+1, multi-factor coefficient recovery, rolling beta = 2) + safe-fail (`tests/test_factors.py`).

Still `DEFER`/`ADAPT_CONCEPT` and **not yet implemented**: economics (point-in-time/vintage handling), catalog/discovery-v2. Each will follow the same pattern (registry entry + independent hand-calc test + optional cross-check). No FinanceToolkit code copied; `THIRD_PARTY_NOTICES.md` unchanged.
