## Revision scope
The documents were revised to improve readability and presentation quality:
- shortened the most verbose titles and section labels;
- increased hierarchy clarity for Part headings;
- simplified figure text to reduce crowding and eliminate overlapping labels;
- improved captions so each visual has a clear descriptive purpose;
- adjusted page spacing, margins, and heading formatting for cleaner page flow;
- embedded bibliography content directly into the LaTeX source so the package is self-contained.
